# RCIP Job Assistant

An AI-powered job search assistant focused on identifying and organizing RCIP (Rural Community Immigration Pilot) job opportunities in Canada.

## 🚀 Project Goal
This system collects job postings, structures the data, and prepares it for AI-based ranking and application assistance.

The final goal is to:
- Find relevant RCIP job opportunities
- Rank jobs based on profile match
- Generate tailored resumes and cover letters
- Support faster and higher-quality job applications (human-reviewed)

## 🛠️ Current Phase
**Phase 1: Job Data Collection**

- Python-based web scraper (requests + BeautifulSoup)
- Git version-controlled development
- Initial dataset generation in CSV format
